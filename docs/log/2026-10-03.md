## 3 October 2026, session approx. 5 hours

Objective: Connect the ESP32 to the computer, set up the repository and get
the first message from the board in the serial monitor.

What I did:
- Connected the ESP32 (ESP-WROOM-32, 30-pin DevKit, USB-UART chip CH9102)
  via micro USB.
- Installed Git, created the esp32-lora-uav-telemetry repository in GitHub
  Desktop and built the folder structure from the handbook using PowerShell.
- Moved the repository from OneDrive to C:\Project and published it on GitHub.
- Created the PlatformIO project firmware/node_a (board: esp32dev,
  framework: Arduino) and set monitor_speed in platformio.ini.
- Wrote the first program that prints a message at start-up, uploaded it
  and read it in the serial monitor.

Result: The board is visible as COM6, the repository is on GitHub,
the ESP32 prints "Hello, ESP32!" in the serial monitor.

Errors and fixes:
1. LED lit, but no COM port in Device Manager.
   Hypothesis: charge-only cable. Confirmed: after replacing the cable, COM6 appeared.
2. "pio" not recognised in the normal terminal.
   Fix: use the PlatformIO terminal (Quick Access > New Terminal).
3. "Arduino.h: No such file" - I ran the code with Code Runner (g++ for the PC).
   Fix: build and upload with PlatformIO, which uses the ESP32 cross-compiler.
4. Build requires both setup() and loop(), even if loop() is empty.
5. Upload failed: "Failed to connect to ESP32: No serial data received".
   Fix: hold BOOT during "Connecting...", release when "Writing at..." appears.
6. Message not visible in the monitor - it is printed only once at start-up.
   Fix: open the monitor, then press EN to restart the board.

Next test: Mini-exercise 1 - start-up banner with node name, firmware version
and reset reason.

Conclusion: If the port is missing, check the cable first. Keep the repository
outside OneDrive. Always build and upload through PlatformIO.

What I learnt:
- cd sets the folder the terminal works in.
- New-Item -ItemType File -Force creates a file together with missing parent folders.
- A path starting with \ begins at the root of the drive; without it (or with .\)
  it begins in the current folder.
- Remove-Item deletes files and folders; -Recurse also deletes their contents.
- Git does not track empty folders, so .gitkeep is used to keep them.
- Commit saves changes locally; push sends them to GitHub.
- The pio command works only in the PlatformIO terminal.
- Code Runner compiles for the PC; the ESP32 needs a cross-compiler (PlatformIO).
- An Arduino program needs #include <Arduino.h> in a .cpp file, setup() and loop().
- Serial.begin(115200) sets the speed on the board; monitor_speed in
  platformio.ini sets it on the computer. Both must match.
- The COM port number exists only on the computer side; it is not used in code.
- Editor autocompletion is a suggestion - always check the inserted values.
- BOOT puts the board into upload mode; EN restarts it.
