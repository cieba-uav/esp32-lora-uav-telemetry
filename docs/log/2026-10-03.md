## 3 October 2026, session approx. 4 hours

Objective: Connect the ESP32 to the computer and set up the project repository.

What I did: Connected the ESP32 via micro USB, installed Git, created the
esp32-lora-uav-telemetry repository in GitHub Desktop, built the folder
structure from the handbook using PowerShell, moved the repository from
OneDrive to C:\Project and published it on GitHub.

Result: The board is visible as COM6, the repository is on GitHub.

Error: The LED on the board was lit, but there was no COM port in Device Manager.

Hypothesis: The cable was charge-only, with no data lines.
Confirmed: After replacing the cable, COM6 appeared.

Next test: pio device list, then the first program with a start-up banner.

Conclusion: If the port is missing, check the cable first.
Keep the repository outside OneDrive.

What I learnt:
- cd sets the folder the terminal works in.
- New-Item -ItemType File -Force creates a file together with any missing
  parent folders.
- A path starting with \ begins at the root of the drive (C:\);
  a path without it (or with .\) begins in the current folder.
- Remove-Item deletes files and folders; -Recurse also deletes their contents.
- Git does not track empty folders, so .gitkeep is used to keep them.
- Commit saves changes locally; push sends them to GitHub.

What I don't know yet:
- How to use foreach in PowerShell to repeat a command for many folders.
- How to upload firmware to the ESP32 and read its output in the serial monitor.
